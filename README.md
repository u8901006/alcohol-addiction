# Alcohol Addiction Research · 酒癮研究文獻日報

每日自動從 PubMed 抓取最新酒精成癮（Alcohol Use Disorder）研究文獻，由 NVIDIA AI 分析總結，生成繁體中文日報。

🔗 **每日日報**: [https://u8901006.github.io/alcohol-addiction/](https://u8901006.github.io/alcohol-addiction/)

## 運作方式

1. **GitHub Actions** 每天 GMT+8 17:50 自動執行
2. **PubMed E-utilities API** 抓取過去 7 天的酒精成癮相關文獻
3. **NVIDIA Nemotron 3 Super** 分析、摘要、分類文獻
4. 生成精美的 **HTML 日報**，部署至 **GitHub Pages**

## AI 模型

- 主要模型：NVIDIA Nemotron 3 Super
- 備用模型：NVIDIA Nemotron 3 Nano
